# 🔧 ADS Arduino Projects Portfolio

A collection of **30 Arduino-based electronics projects** developed using the **ADS Arduino Inventor Kit** by **Alphadigitronix Solutions**.

These projects cover sensor interfacing, automation, safety systems, actuator control, environmental monitoring, distance measurement, obstacle detection, LCD interfacing, relay control, and basic embedded-system concepts.

---

## 👨‍💻 About

This repository contains hands-on Arduino and embedded-system projects designed for beginners, students, makers, and electronics enthusiasts.

The projects focus on learning Arduino through practical experiments using sensors and components included in the **ADS Arduino Inventor Kit**.

Each project is maintained in its own GitHub repository with Arduino source code, circuit connections, documentation, and other supporting information.

# 🚀 Getting Started

### 1. Select a Project

Choose any project from the table above.

### 2. Open the Repository

Click **View Project** to open the individual GitHub repository.

### 3. Build the Circuit

Follow the component connection table provided in the project's `README.md`.

### 4. Open the Arduino Code

Download or copy the `.ino` file and open it using the Arduino IDE.

### 5. Connect Arduino UNO

Connect the Arduino UNO to the computer using the USB cable.

### 6. Upload

Select:

`Tools → Board → Arduino UNO`

Select the correct COM port and upload the program.

### 7. Test

Follow the testing instructions provided in the individual project README.

# ⚠️ Safety

These projects are intended primarily for **educational and low-voltage electronics experimentation**.

- Verify all wiring before powering the circuit.
- Avoid short circuits between 5V and GND.
- Use resistors with LEDs.
- Do not power motors or other high-current loads directly from Arduino I/O pins.
- Use an appropriate external supply where required.
- Maintain a common ground when external low-voltage supplies are used.
- Exercise additional care when working with relay modules.
- Beginners should use LEDs or other low-voltage loads for relay demonstrations.
- Do not experiment with exposed household AC mains.
