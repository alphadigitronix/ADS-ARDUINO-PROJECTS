# 🔧 Arduino Projects Portfolio

A collection of Arduino-based electronics projects developed and simulated using Tinkercad.

These projects cover sensor interfacing, automation, safety systems, actuator control, touch control, distance measurement, obstacle detection, and basic embedded-system concepts.

---

## 👨‍💻 About

This repository contains my hands-on Arduino and embedded-systems projects, focusing on sensor interfacing, automation, safety systems, actuator control, distance measurement, obstacle detection, and practical electronics applications.
